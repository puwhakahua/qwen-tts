# qwen-tts

Uses [qwen-tts](https://github.com/Qwen/Qwen3-TTS) for text-to-speech (TTS) tasks. 

Uses PyTorch 2.10 and qwen-tts 0.1.1.

## Quick start

### Inhouse registry

* Log into registry using *public* credentials:

  ```bash
  docker login -u public -p public public.aml-repo.cms.waikato.ac.nz:443 
  ```

* Pull and run image (adjust volume mappings `-v`):

  ```bash
  docker run -u $(id -u):$(id -g) -e USER=$USER --shm-size 8G --net=host \
    -v /local/cache:/.cache \
    -v /local/dir:/container/dir \
    -it harbor.cms.waikato.ac.nz/public/puwhakahua/qwen-tts:0.1.1_cuda
  ```

### Docker hub

* Pull and run image (adjust volume mappings `-v`):

  ```bash
  docker run -u $(id -u):$(id -g) -e USER=$USER --shm-size 8G --net=host \
    -v /local/cache:/.cache \
    -v /local/dir:/container/dir \
    -it waikatodatamining/qwen-tts:0.1.1_cuda
  ```

### Build local image

* Build the image from Docker file (from within /path_to/qwen-tts/1.8.0_cuda)

  ```bash
  docker build -t qwen-tts .
  ```
  
* Run the container

  ```bash
  docker run -u $(id -u):$(id -g) -e USER=$USER --shm-size 8G --net=host \
    -v /local/cache:/.cache \
    -v /local/dir:/container/dir \
    -it qwen-tts
  ```
  `/local/dir:/container/dir` maps a local disk directory into a directory inside the container


## Publish images

### Build

```bash
docker build -t qwen-tts:0.1.1_cuda .
```

### Inhouse registry  

* Tag

  ```bash
  docker tag \
    qwen-tts:0.1.1_cuda \
    harbor.cms.waikato.ac.nz/public/puwhakahua/qwen-tts:0.1.1_cuda
  ```
  
* Push

  ```bash
  docker push harbor.cms.waikato.ac.nz/public/puwhakahua/qwen-tts:0.1.1_cuda
  ```
  If error "no basic auth credentials" occurs, then run (enter username/password when prompted):
  
  ```bash
  docker login public-push.aml-repo.cms.waikato.ac.nz:443
  ```

### Docker hub  

* Tag

  ```bash
  docker tag \
    qwen-tts:0.1.1_cuda \
    waikatodatamining/qwen-tts:0.1.1_cuda
  ```
  
* Push

  ```bash
  docker push waikatodatamining/qwen-tts:0.1.1_cuda
  ```
  If error "no basic auth credentials" occurs, then run (enter username/password when prompted):
  
  ```bash
  docker login
  ``` 


### Requirements

```bash
docker run --rm --pull=always -u $(id -u):$(id -g) -e USER=$USER \
  -v `pwd`:/workspace \
  --entrypoint /opt/qwen-tts/bin/pip \
  -it harbor.cms.waikato.ac.nz/public/puwhakahua/qwen-tts:0.1.1_cuda \
  --no-cache-dir freeze > requirements.txt
```


## Permissions

When running the docker container as regular use, you will want to set the correct
user and group on the files generated by the container (aka the user:group launching
the container):

```bash
docker run -u $(id -u):$(id -g) -e USER=$USER ...
```
